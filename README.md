# 📱 Script Mate - 로컬 실행 가이드

## 🚀 빠른 시작

### 1️⃣ 필요한 것 설치

```bash
# Python 3.8 이상 설치되어 있는지 확인
python --version

# FastAPI 및 필요한 패키지 설치
pip install fastapi uvicorn jinja2 python-multipart
```

### 2️⃣ 폴더 구조 만들기

```
프로젝트폴더/
├── main.py
├── templates/
│   ├── home.html
│   ├── select_role.html
│   └── practice.html
└── scripts/
    └── _최종_오감언쟁_연극패청년_신입기수공연_2602_numbering.txt
```

**중요:** 
- `templates/` 폴더에 HTML 파일 3개
- `scripts/` 폴더에 `_numbering.txt` 대본 파일

### 3️⃣ 서버 실행

```bash
# 터미널에서 프로젝트 폴더로 이동
cd 프로젝트폴더

# 서버 시작
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 4️⃣ 브라우저에서 접속

**컴퓨터에서:**
```
http://localhost:8000
```

**스마트폰에서 (같은 와이파이):**
```
http://컴퓨터IP주소:8000
```

컴퓨터 IP 확인 방법:
- Windows: `ipconfig` (예: 192.168.0.5)
- Mac/Linux: `ifconfig` 또는 `hostname -I`

## 📱 모바일 최적화 완료!

### ✅ 수정된 기능

1. **화면 크기 최적화**
   - 모바일 해상도에 맞춤
   - 화면이 움직이지 않도록 고정
   - viewport 설정으로 확대/축소 방지

2. **폰트 크기 개선**
   - 대사: 16px (모바일 읽기 좋은 크기)
   - 역할명: 13px
   - 답변: 14px

3. **키보드 입력창 고정**
   - 화면 하단에 sticky 고정
   - 키보드 올라올 때 함께 올라감
   - iOS/Android 모두 대응

4. **다음 버튼 추가**
   - 입력창 옆에 "다음" 버튼
   - 클릭 시 내 차례로 건너뛰기
   - 현재 내 차례면 정답 보고 넘어가기

5. **번호 점프 버그 수정**
   - `parseInt(item.idx)`로 정확한 숫자 비교
   - 점프 시 화면 초기화
   - 점프 위치 명확히 표시

## 🎯 사용 방법

### 연습 시작
1. "연습 시작" 버튼 클릭
2. 배역 선택 (라디오 버튼)
3. "연습 시작하기" 클릭

### 연습 중
- **대사 입력**: 대사 치고 엔터 또는 "전송"
- **건너뛰기**: "다음" 버튼 (정답 보고 넘어감)
- **번호 이동**: 숫자만 입력 (예: 25)
- **힌트 보기**: 빈 엔터 (정답 표시)

### 키보드 단축키
- `Enter`: 전송
- `Shift + Enter`: 줄바꿈
- 숫자만 입력: 해당 번호로 점프

## 🔧 문제 해결

### 포트가 이미 사용 중일 때
```bash
# 다른 포트로 실행
uvicorn main:app --reload --port 8080
```

### 모바일에서 접속 안 될 때
1. 방화벽 확인
2. 같은 Wi-Fi 연결 확인
3. IP 주소 정확히 확인

### 대본 파일이 안 보일 때
- `scripts/` 폴더 확인
- 파일명이 `_numbering.txt`로 끝나는지 확인

## 📂 대본 파일 형식

```
[0] (지문): 오감언쟁
[1] (지문): 극: 이해섬
[2] (지문): 각색: 김아형
[7] 눈: (졸린 듯) 피곤하다. 언제까지 읽을 거야.
[8] 오른손: (지친 듯) 내 말이.
```

형식: `[번호] 역할: 대사내용`
